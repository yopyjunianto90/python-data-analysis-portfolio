# Python Data Analysis Portfolio
Portofolio ini berisi project Python untuk data cleaning, web scraping, dan analisis finansial.

## Project Utama
- Scraping harga saham IDX
- Analisis data penjualan manufaktur
- Visualisasi tren dengan Matplotlib/Seaborn

## Cara Menjalankan
1. Clone repo ini
2. Install requirements: `pip install -r requirements.txt`
3. Jalankan script sesuai folder project
